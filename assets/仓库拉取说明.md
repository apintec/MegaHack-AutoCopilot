## 使用方法
### 第一次拉取主仓库
- 1、打开命令行或终端，导航到主项目的根目录。
- 2、确保子模块已经初始化。如果尚未初始化，请运行以下命令：
	```
	git submodule init
	```
- 3、更新子模块。运行以下命令：
	```
	git submodule update
	```
这将会拉取子模块的最新提交，并将其更新到主项目中。


### 拉取主项目时候同时拉取子模块
- 1、当克隆包含子模块的 Git 项目时，可以使用一下命令来确保同时克隆子模块：
	```
	git clone --recurse-submodule <repository_url>
	```
这样，Git 不仅会克隆主项目，还会同时克隆所有子模块。

- 2、如果你忘记使用 **--recurse-submodule**，在克隆完成后可以通过下面命令初始化和更新子模块
	```
	git submodule update --init --recursive
	```

### 如果子模块已经存在
- 1、如果子模块已经存在，并且需要更新到最新版本，可以运行以下命令：
	```
	git submodule update --remote
	```
这将会从子模块的远程仓库拉取最新的更改，并将其更新到主项目中

- 2、如果需要更新多个层级的子模块，可以使用以下命令：
	```
	git submodule update --recursive
	```
- 3、如果子模块已经更新，但主项目中的引用仍然指向旧的提交，可以运行以下命令来更新主项目中的引用：
	```
	git add <submodule_path>
	git commit -m "Update submodule to the latest commit"
	```
	其中 <submodule_path> 是子模块在主项目中的相对路径
